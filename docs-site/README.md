# Hang Out Docusaurus Docs

This folder contains project documentation for:

- Supabase table schema and relationships
- End-to-end product flows (account, profile, activity, AI match, chat)
- Architecture diagrams (Mermaid)

## Install

```bash
npm install
```

## Run locally

```bash
npm run start
```

## Build

```bash
npm run build
```

## Serve the built static site

```bash
npm run serve
```
